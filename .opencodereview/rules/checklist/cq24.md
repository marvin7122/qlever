# CQ24: Inappropriate Intimacy

## Statement
Inappropriate Intimacy: two classes in the diff reach deep into each other's private state (friend abuse, getters returning internals, shared mutable globals) — reduce coupling; move shared logic to one owner. [Fowler, Refactoring 2nd ed: Inappropriate Intimacy; Ousterhout APoSD ch. 5]  (overlaps CQ4 — report CQ4 when it is about a leaked design decision)
