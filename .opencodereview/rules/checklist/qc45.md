# QC45: Binary persistence uses the serialization framework

## Statement
Binary persistence uses the serialization framework: `AD_SERIALIZE_FUNCTION` / `AD_SERIALIZE_FRIEND_FUNCTION` and existing (de)serializers — no hand-rolled fread/fwrite of struct bytes. (see src/util/Serializer/Serializer.h:110-133)
