# CQ29: Shallow module

## Statement
Shallow module: a new public interface exposes nearly as much surface as its implementation (low interface:implementation ratio; every public method is a 1-line pass-through) — deepen the interface or merge the module. [Ousterhout APoSD ch. 4]  (overlaps CQ3 — report CQ3 for pure pass-through wrappers)
