# CQ59: [MAY] Log level discipline

## Statement
[MAY] Log level discipline: ERROR/WARN reserved for actionable operator-visible problems; DEBUG for dev detail — flag ERROR used for expected/normal conditions, or DEBUG used for things operators must see.
