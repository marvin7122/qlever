# QC11: Each file starts with the standard QLever copyright/author header block

## Statement
Each file starts with the QLever copyright header in its current form. A new file gets the header below with the author's own line; an existing file that is changed keeps its history lines and the author adds a line for themselves if not yet present. The form is: `// Copyright <years> The QLever Authors, in particular:`, a blank `//` line, one line per author as `// <years> <Name> <email>, UFR` (the `, UFR` suffix for members of the chair; other affiliations are spelled out), a blank `//` line, the legend `// UFR = University of Freiburg, Chair of Algorithms and Data Structures`, a blank `//` line, and the two licence lines `// You may not use this file except in compliance with the Apache 2.0 License,` / `// which can be found in the `LICENSE` file at the root of the QLever project.`, then an empty line before the include guard or the first include. The legacy three-line header and the comma form `Copyright 2026, The` are not used in new or touched files.
