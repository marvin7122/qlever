# QC35: Strings/IRIs created at query time go into the `LocalVocab` via …

## Statement
Strings/IRIs created at query time go into the `LocalVocab` via `getIndexAndAddIfNotContained` (or the `...IfContained` lookup variant); the local vocabs of all input results are propagated/merged into the output `Result`, never dropped. (see src/index/LocalVocab.h:86)
