# QC38: A new `SparqlExpression` implements `evaluate(EvaluationContext*)`, …

## Statement
A new `SparqlExpression` implements `evaluate(EvaluationContext*)`, `getCacheKey(VariableToColumnMap)`, `isDeterministic()`, and children access; aggregate/lang-filter hooks (`isAggregate`, `getLanguageFilterExpression`) only when semantically applicable. (see src/engine/sparqlExpressions/SparqlExpression.h)
