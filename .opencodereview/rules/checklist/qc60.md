# QC60: Exception assertions use `AD_EXPECT_THROW_WITH_MESSAGE` / …

## Statement
Exception assertions use `AD_EXPECT_THROW_WITH_MESSAGE` / `AD_EXPECT_THROW_WITH_MESSAGE_AND_TYPE` from test/util/GTestHelpers.h, not bare `EXPECT_THROW` when the message matters. (see test/util/GTestHelpers.h:61,81)
