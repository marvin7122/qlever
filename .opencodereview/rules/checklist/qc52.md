# QC52: Cleanup code paths that may throw are wrapped with `ad_utility::terminateIfThrows` / …

## Statement
Cleanup code paths that may throw are wrapped with `ad_utility::terminateIfThrows` / `ignoreExceptionIfThrows` (ExceptionHandling.h) or `OnDestructionDontThrowDuringStackUnwinding` — destructors never propagate exceptions. (see src/util/ExceptionHandling.h:32,61; src/util/OnDestructionDontThrowDuringStackUnwinding.h)
