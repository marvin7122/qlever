# CQ25: Large Class

## Statement
Large Class: a new/modified class >~400 lines or with >~15 public members doing several unrelated jobs — split by responsibility. [Fowler, Refactoring 2nd ed: Large Class; McConnell, Code Complete 2 ch. 5]  (overlaps CQ2 for a single oversized function — report CQ2)
