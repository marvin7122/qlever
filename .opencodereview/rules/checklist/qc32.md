# QC32: `VariableToColumnMap` entries are built with `makeAlwaysDefinedColumn` / …

## Statement
`VariableToColumnMap` entries are built with `makeAlwaysDefinedColumn` / `makePossiblyUndefinedColumn` and the UNDEF status is correct (e.g. OPTIONAL introduces possibly-undefined). (see src/engine/VariableToColumnMap.h:52-59)
