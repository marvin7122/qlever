# QC41: New global constants go to src/global/Constants.h

## Statement
New global constants go to src/global/Constants.h; special/typed IDs use src/global/SpecialIds.h / TypedIndex.h — no new magic `ValueId` bit patterns invented inline. (see src/global/Constants.h, src/global/SpecialIds.h)
