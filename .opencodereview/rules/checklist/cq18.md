# CQ18: Primitive Obsession

## Statement
Primitive Obsession: domain concepts (IDs, sizes, index/offset, duration, count, mode, unit) passed as raw int/size_t/string where a small named type would prevent misuse — introduce a value type. [Fowler, Refactoring 2nd ed: Primitive Obsession; Pragmatic Programmer: DRY]  (overlaps QC4 for column indices — report QC4)
