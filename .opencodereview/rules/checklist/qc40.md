# QC40: IRIs/literals are handled via the `src/rdfTypes` classes (`Iri`/`IriView`, `Literal`) …

## Statement
IRIs/literals are handled via the `src/rdfTypes` classes (`Iri`/`IriView`, `Literal`) with the `fromStringRepresentation`/`toStringRepresentation` inverse pair; escaping via `RdfEscaping.h`; no hand-concatenated `"<" + iri + ">"`. (see src/rdfTypes/Iri.h:73-76, src/rdfTypes/RdfEscaping.h)
