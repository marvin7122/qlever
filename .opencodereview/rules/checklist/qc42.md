# QC42: Hash containers are `ad_utility::HashMap`/`HashSet` (absl wrappers), not …

## Statement
Hash containers are `ad_utility::HashMap`/`HashSet` (absl wrappers), not `std::unordered_map/set` or raw absl types; use `HashMapWithMemoryLimit`/`HashSetWithMemoryLimit` when size depends on query data. (see src/util/HashMap.h:20, src/util/HashSet.h:25-35)
