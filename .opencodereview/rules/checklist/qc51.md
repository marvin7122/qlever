# QC51: Shared mutable state uses `ad_utility::Synchronized`, `TaskQueue`, `ThreadSafeQueue`, or …

## Statement
Shared mutable state uses `ad_utility::Synchronized`, `TaskQueue`, `ThreadSafeQueue`, or `jthread.h` — not bare `std::mutex` + manual lock discipline scattered across the class. (see src/util/Synchronized.h, src/util/TaskQueue.h, src/util/ThreadSafeQueue.h)
