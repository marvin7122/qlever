# QC43: Memory quantities are `ad_utility::MemorySize` (`_GB`/`_MB` literals)

## Statement
Memory quantities are `ad_utility::MemorySize` (`_GB`/`_MB` literals); query-data-sized allocations go through `AllocatorWithLimit`/`makeAllocatorWithLimit`, not unlimited default allocation. (see src/util/AllocatorWithLimit.h:140,272)
