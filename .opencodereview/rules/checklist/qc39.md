# QC39: Id → value conversion inside expressions uses the existing value getters …

## Statement
Id → value conversion inside expressions uses the existing value getters (`StringValueGetter`, `LiteralFromIdGetter`, etc. in SparqlExpressionValueGetters.h) instead of a manual `Datatype` switch. (see src/engine/sparqlExpressions/SparqlExpressionValueGetters.h:169,310)
