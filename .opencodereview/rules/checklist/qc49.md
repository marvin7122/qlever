# QC49: Logging uses the Log.h macros (`AD_LOG_INFO`, `AD_LOG_DEBUG`, `AD_LOG_TIMING`, 

## Statement
Logging uses the Log.h macros (`AD_LOG_INFO`, `AD_LOG_DEBUG`, `AD_LOG_TIMING`, ... with `LogLevelEnum`), not std::cout/cerr; long index-build loops report progress via `ad_utility::ProgressBar` and end with `getFinalProgressString()`. (see src/util/Log.h:84-86, src/util/ProgressBar.h:54,142)
