# CQ17: Data Clumps

## Statement
Data Clumps: >=3 fields/params that recur together at >=2 call sites (the same tuple of types/args passed around) — extract a named struct/value type. [Fowler, Refactoring 2nd ed: Data Clumps]  (overlaps CQ5 for a single long parameter list — report CQ5 when it is just one function's arity)
