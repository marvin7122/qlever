# QC28: `IdTable`s created in `computeResult` use the context allocator (`allocator()` → …

## Statement
`IdTable`s created in `computeResult` use the context allocator (`allocator()` → `QueryExecutionContext::getAllocator()`, an `AllocatorWithLimit<Id>`), never a fresh unlimited allocator. (see src/engine/Operation.h:382, src/engine/QueryExecutionContext.h:157)
