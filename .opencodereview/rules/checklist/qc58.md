# QC58: New engine/util sources are added to the `add_library(...)` source list of the …

## Statement
New engine/util sources are added to the `add_library(...)` source list of the directory's CMakeLists.txt and dependencies linked via the `qlever_target_link_libraries` wrapper (not raw `target_link_libraries`, except the existing http special case). (see src/engine/CMakeLists.txt:2-38)
