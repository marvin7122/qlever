# CQ41: Misuse resistance

## Statement
Misuse resistance: a public API is easy to call wrong (bool flag whose meaning depends on call order, raw pointer with unclear ownership, a param that must be non-null but isn't typed as such) — make correct usage the easy/only one (strong types, enums, explicit ownership).
