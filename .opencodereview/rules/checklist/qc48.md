# QC48: Generators use the in-repo `cppcoro::generator` (src/util/Generator.h) or …

## Statement
Generators use the in-repo `cppcoro::generator` (src/util/Generator.h) or `ad_utility::streams::stream_generator` for chunked HTTP output — no new coroutine machinery; a simple state-machine range via InputRangeUtils.h is preferred when it suffices. (see src/util/Generator.h:47, src/util/stream_generator.h)
