# QC25: Distinguish declarations used as interfaces from definitions used as implementations

## Statement
Distinguish declarations used as interfaces from definitions used as implementations. Keep ordinary non-template function and method definitions in `.cpp` files. Keep definitions in headers only when they are function templates, class-template members, `constexpr`/`consteval` functions, short trivial functions, or otherwise technically required to be visible at the call site. Header-defined non-template functions must be ODR-safe, normally by being `inline`. Prefer `.cpp` definitions for longer, allocation-heavy, or implementation-dependent functions.
