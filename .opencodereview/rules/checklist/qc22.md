# QC22: Coupled-lifetime locals (owner ⊇ table ⊇ view) bundled in an owner struct so declaration …

## Statement
Coupled-lifetime locals (owner ⊇ table ⊇ view) bundled in an owner struct so declaration order enforces lifetime; derived views recomputed via accessor, not stored self-referentially.

b [SHOULD] Returned lazy ranges/views must be lifetime-correct *by construction* (value-capture handles; no `[&param]` into a returned pipeline). See CPP11 / CPP54b / PP19 and `~/.claude/qlever-code-review-guidelines.md`.
