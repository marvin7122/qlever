# CQ51: Low cohesion

## Statement
Low cohesion: a new function/class mixes unrelated responsibilities (would need >1 reason to change) — split it. [McConnell, Code Complete 2 ch. 5 (cohesion) / ch. 7; Ousterhout APoSD ch. 9]  (overlaps CQ2/CQ25 for size — report those)
