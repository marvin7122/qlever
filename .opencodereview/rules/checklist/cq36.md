# CQ36: Vague name

## Statement
Vague name: a new identifier whose meaning can't be pinned down (data, tmp, result, handle, process, doStuff) without reading the body — rename to a precise, specific name. [Ousterhout APoSD ch. 14 / ch. 19 (Red Flags)]  (overlaps QC14/QC15 — report QC14/15 for project naming)
