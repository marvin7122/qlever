# CQ49: New public behavior has a direct test

## Statement
New public behavior has a direct test: every new public function/branch in the diff is covered by a test that fails without it — no logic hidden only in untested private helpers. [Google eng-practices: Tests; McConnell, Code Complete 2 ch. 22]  (overlaps CQ13/PP17 — report PP17)
