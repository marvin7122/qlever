# PP22: Overly permissive typed interfaces

## Statement
New overloads and compile-time APIs reject invalid type combinations at compile time rather than silently converting values across semantic domains (for example Boolean and Integer columns).

## Sources
- review: `.ai-review/personal_pitfalls.md#PP22` Mined from maintainer review comments, file dated 2026-09-22.
- review: `QLever PR #114` "The integral CellWriter overload also handles ColumnType::Boolean, which allows passing any integral type (e.g., int/char) to a Boolean column and also allows bool to be passed to an Integer column. This weakens the type-safety implied by ColumnType and can silently serialize unintended values as \"true\"/\"false\"."
