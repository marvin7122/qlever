# PP25: Build flags must be scoped and singular

## Statement
New compiler options are applied only to the affected compiler/language/target, are not duplicated, and do not globally weaken diagnostics or semantics without a narrowly documented justification.

## Sources
- review: `.ai-review/personal_pitfalls.md#PP25` Mined from maintainer review comments, file dated 2026-09-22.
- review: `QLever PR #121` "Setting `CMAKE_CXX_FLAGS` globally to add `-fpermissive` affects all targets and toolchains (including non-GNU compilers) and is hard to override. Prefer `add_compile_options` scoped to C++ and guarded by the affected compiler(s) so the workaround doesn't silently change semantics elsewhere."
- review: `QLever PR #121` "This conditional `add_compile_options(-fpermissive)` duplicates the earlier addition of `-fpermissive`. Keeping it in exactly one place avoids accidentally applying the flag twice or having diverging conditions over time."
- review: `.opencodereview/rule.json#141` QLever OCR fan-out project rule, file dated 2026-09-23.
