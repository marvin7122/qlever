# PP16: Missing assertions / unsafe constructs

## Statement
Preconditions in new code are guarded with `AD_CONTRACT_CHECK`/`AD_CORRECTNESS_CHECK`; no UB (end-iterator dereference), no ignored resource handles (`[[nodiscard]]`), memory-limit/lifetime concerns addressed.
