# PP18: Wrong file/namespace placement & missing self-review

## Statement
New code lives in the appropriate module/namespace (e.g. `qlever::constructExport`), helpers go to `util/`, file moves use `git mv`; author has self-reviewed the diff before requesting review (Sonar issues fixed, TODOs resolved or ticketed).
